# commonstats — crate guide

`commonstats` is the WASM-first Rust statistical core: special functions,
mergeable accumulators, descriptives, hypothesis tests, kernel density and
auto-histograms, and distribution-free transforms, all `&[f64]` in / struct
out with no binding glue. The full function-by-function API reference is the
crate README: [`../../../CommonStats/README.md`](../../../CommonStats/README.md).

## Modules and features

| Module        | Feature gate | Purpose                                                        |
|----------------|--------------|------------------------------------------------------------------|
| `special`      | (base)       | special functions backing the rest of the crate                  |
| `accum`        | (base)       | mergeable accumulator core, plus `accum::histogram` (fixed-bin histogram + ECDF) |
| `descriptive`  | (base)       | descriptives and moments                                          |
| `density`      | (base)       | kernel density estimation and auto-histograms                     |
| `transform`    | (base)       | distribution-free transforms (rank, normal-scores, Box–Cox, Yeo–Johnson, quantile-normalize) |
| `htest`        | (base)       | hypothesis tests, effect sizes, confidence intervals               |
| `error`        | (base)       | `StatError`                                                       |
| `nan`          | (base)       | `NanPolicy`                                                        |
| `dist`         | `dist`       | continuous + discrete distribution objects (CDF/SF/PDF/quantile) and PIT |
| `rng`          | `rng`        | counter-based Philox RNG (`CommonStatsRng`)                        |
| `resample`     | `resample`   | permutation/bootstrap index generation, `NullDist`/`BootDist` (implies `rng`) |

(Source: `Cargo.toml` `[features]`, `src/lib.rs` `pub mod` lines and header doc comment.)

## Conventions policy

Every public statistic states its convention — `ddof`, definition, degrees of
freedom, sidedness, and any correction — plus the oracle it is validated
against, in its own rustdoc comment. `cargo doc --open` (or docs.rs once a
release ships) is the reference for those per-item conventions; this guide
does not restate them.

## Oracle harness

Fixtures are generated by `CommonStats/scripts/gen_oracle.py`, run manually on
a dev machine (`python scripts/gen_oracle.py [area ...]`, default all areas:
special, htest, dist, density, transform). It uses mpmath at 60 decimal digits
as the truth arbiter (Layer 1) and cross-checks bulk quantities against scipy
and R at generation time (Layer 2, `rel 1e-9`), stamping both cross-check
values into the fixture as permanent provenance. mpmath/scipy/R are
generation-time tools only, never crate or CI dependencies — CI runs `cargo
test` against the fixtures already committed in `CommonStats/tests/fixtures/`.

## CI gates

For the `CommonStats` matrix entry in `.github/workflows/ci.yml`:

- `cargo fmt --all -- --check`
- `cargo build --all-features`
- `cargo test --all-features`
- `cargo clippy --all-targets --all-features -- -D warnings`
- `cargo build --all-features --target wasm32-unknown-unknown` (separate `wasm` job)
